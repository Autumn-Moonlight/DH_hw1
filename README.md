## 实现思路
首先是CMake部分，这一部分主要是根据学长在课上所讲的内容来完成的（学长给出了万用的实例）

然后是对目标要求的解读，首先简单阅读src文件夹里的文件和inc文件夹里的文件
对加减法的实现都是将矩阵运算转化为数组运算来进行，思路很简单
矩阵的乘法是根据运算法则将元素一一对应进行运算后加和获得结果，在将结果录入数组的相应位置
矩阵的数乘就是将数组的每一个数放大
矩阵的转置就是将原矩阵的数组对应位置的元素给横纵坐标交换位置的数组赋值，产生一个新的数组，这个数组所在的结构就是所求矩阵
矩阵求值就是判定为方阵后，根据拉普拉斯定理对矩阵进行展开，采用递归的方式来进行计算
求逆矩阵就是判定为方阵后，计算Astar矩阵，对Astar矩阵求值并将结果赋值给一个新的矩阵结构的数组的相应位置，再进行一次数乘运算得到目标矩阵
求矩阵的秩思路有误
求矩阵的迹就是把对角线上的元素加和取结果
